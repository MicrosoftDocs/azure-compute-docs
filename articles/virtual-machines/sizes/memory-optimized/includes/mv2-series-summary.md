# Customer intent: "As a cloud architect, I want to review the specifications and performance capabilities of the Mv2-series virtual machines, so that I can determine their suitability for deploying memory-intensive applications and large in-memory databases."
---
Msv2 High Memory series instances are memory optimized VM sizes providing unparalleled computational performance to support large in-memory databases and workloads, with a high memory-to-CPU ratio that is ideal for relational database servers, large caches, and in-memory analytics. All Msv2 High Memory series virtual machine sizes can use both standard and premium persistent disks.
